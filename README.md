# Версия для слабовидящих — accessible-version.js

Самостоятельный плагин специальных возможностей. Написан с нуля, без стороннего кода, зависимостей и сборки. Лицензия MIT — авторство указывать не требуется, никаких обязательных упоминаний.

Подходит для обычных HTML-страниц, Vue, Nuxt, React, Angular — подключается одним тегом `<script>`.

---

## Возможности (ГОСТ Р 52872-2019)

- **Размер текста** — фиксированные коэффициенты: 100% → 150% → 200%
- **Цветовые схемы**:
  - чёрным по белому (основная)
  - белым по чёрному
  - тёмно-синим по голубому
- **Межбуквенный интервал (кернинг)** — обычный / средний / большой
- **Фильтры**: инверсия цветов, оттенки серого (можно сочетать со схемами)
- **Скрыть изображения** — скрывает `<img>`, `<video>`, `<figure>`, `[role=img]` **и CSS `background-image`** (важно для сайтов, где галереи выводятся фоном элементов)
- **Увеличенный межстрочный интервал** — двойной интервал для текста

Шрифт панели — **Montserrat** (подключается автоматически, только если сайт сам его не использует). Настройки сохраняются в `localStorage` и применяются на всех страницах сайта, где подключён плагин.

## Кнопка вызова

Кнопка располагается **вверху страницы** — как принято на ГОСТ-версиях сайтов.

### Вариант 1: своя кнопка в шапке (рекомендуется)

Добавьте атрибут `data-av-trigger` любой кнопке в шапке сайта:

```html
<button type="button" data-av-trigger>Версия для слабовидящих</button>
<script src="accessible-version.js" defer></script>
```

Плагин сам вставит иконку очков в кнопку, добавит ARIA-атрибуты и откроет панель по клику. Если кнопка появляется в DOM позже (SPA-роутинг), плагин найдёт её автоматически.

### Вариант 2: без своей кнопки

Если кнопки с `data-av-trigger` нет, плагин создаст компактную кнопку «Версия для слабовидящих» в правом верхнем углу экрана.

Панель настроек раскрывается под кнопкой (или над ней, если снизу нет места) и всегда остаётся в пределах экрана.

## Подключение

### Обычный сайт

```html
<script src="accessible-version.js" defer></script>
```

### Vue / Nuxt (SPA)

Положите файл в папку `public/` (Nuxt) или `public/` (Vue CLI) / `static/`:

```html
<!-- nuxt.config.ts / vue.config: просто добавить в head -->
export default {
  head: {
    script: [
      { src: '/accessible-version.js', defer: true }
    ]
  }
}
```

Либо в корневом шаблоне (`app.vue`, `layouts/default.vue`):

```html
<script>
export default {
  mounted() {
    if (!window.AccessibleVersion) {
      const s = document.createElement('script');
      s.src = '/accessible-version.js';
      s.defer = true;
      document.head.appendChild(s);
    }
  }
}
</script>
```

Плагин одинаково работает на страницах с разными фреймворками: он не меняет DOM приложения и не мешает гидрации.

### Next.js / React

```tsx
// app/layout.tsx или pages/_app.tsx
import Script from 'next/script';

<Script src="/accessible-version.js" strategy="afterInteractive" />
```

## Как это работает

| Режим | Механизм |
|---|---|
| Цветовые схемы | CSS-классы на `<html>` (`av-scheme-*`): все элементы принудительно перекрашиваются (фоны — в прозрачность, текст и рамки — в цвет схемы), фоновые картинки удаляются |
| Кернинг | CSS-классы `av-kern-medium` / `av-kern-large` → `letter-spacing: 0.06em / 0.12em` |
| Инверсия / оттенки серого | CSS `filter` на корневом элементе `<html>` |
| Скрыть изображения | CSS-класс на `<html>`: прячет `img/picture/video/canvas/figure/[role=img]` и отключает `background-image` у всех элементов |
| Межстрочный интервал | CSS-класс на `<html>`, `line-height: 2` для текстовых блоков |
| Размер текста | `font-size` в процентах на `<html>` (100 / 150 / 200) |

Важные архитектурные решения:

- **Интерфейс изолирован в Shadow DOM.** Стили сайта не ломают кнопку и панель, а виджет не влияет на стили сайта. Проверено с агрессивными глобальными стилями (`* { margin: 0 }` и т.п.).
- **Фильтр применяется к корню документа.** По спецификации CSS Filter Effects фильтр на корневом элементе не создаёт содержащий блок, поэтому элементы с `position: fixed` (плавающие кнопки, шапки) продолжают работать корректно при прокрутке. Это устраняет «прыгающий» интерфейс, характерный для многих подобных виджетов.
- **DOM страницы не модифицируется** — не добавляются skip-ссылки, не переписываются атрибуты, не создаются стили внутри тела страницы. Это исключает конфликты с гидрацией Vue/Nuxt/React.
- **Состояние сохраняется в `localStorage`** под ключом `accessible-version-settings` и применяется при загрузке страницы.

## Адаптация сайта под крупный масштаб (150% / 200%)

При увеличении текста у любого сайта «поплывёт» вёрстка — это неизбежно. Плагин даёт два механизма борьбы:

**1. Автоматическое антипереполнение (встроено).** При масштабах 150%/200% плагин добавляет на `<html>` классы `av-scale-150` / `av-scale-200` и подключает правила: текст в кнопках переносится вместо вылезания (`white-space: normal`), картинки не шире своего блока, длинные слова рвутся (`overflow-wrap: break-word`).

**2. Свои стили поверх.** На сайте можно донастроить конкретные блоки под крупный масштаб, используя эти же классы:

```css
/* Пример: на 200% скрыть декоративные элементы шапки и
   перестроить меню в одну колонку */
html.av-scale-200 .header-decor { display: none; }
html.av-scale-200 .main-menu { flex-direction: column; }

/* Демо-страница так же сделана: контейнер 1500px, кнопка шапки тянется */
```

## Публичный API

```js
window.AccessibleVersion.open();   // открыть панель
window.AccessibleVersion.close();  // закрыть панель
window.AccessibleVersion.reset();  // сбросить все настройки
window.AccessibleVersion.rescan(); // повторно найти кнопки [data-av-trigger] (после смены роута в SPA)
```

Пример: своя кнопка в шапке сайта

```html
<button onclick="AccessibleVersion.open()">Версия для слабовидящих</button>
```

## Доступность самого виджета

- Полная навигация с клавиатуры: Tab / Shift+Tab, Enter, Escape
- Фокус зациклен внутри панели (WCAG 2.1.2 No Keyboard Trap)
- После закрытия фокус возвращается на кнопку
- ARIA-роли: `dialog`, `radiogroup`, `radio`, `switch`
- `aria-expanded` на кнопке-триггере, `aria-checked` на переключателях
- Видимые индикаторы фокуса (WCAG 2.4.7)
- Уважение `prefers-reduced-motion`
